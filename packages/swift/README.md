# SLLABKit

Swift package shared by `fixture-ios` and `film-ios`: models, the auth session, the
Supabase and API clients, and shared SwiftUI components and theme. Not built yet.

Starts as code moved out of Fixture (`Models/`, `Services/`, `Theme/`) when Film adopts
accounts. Once it has a `Package.swift`, add it to `SLLAB.xcworkspace` and to both app
projects as a local package.
