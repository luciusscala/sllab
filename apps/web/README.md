# web

The platform web app: the team app on the web, the manager console (roster, schedule,
people, messages, stats), the club-site editor, and the host for iOS universal links.

Not built yet. The team app (`src/app/team`) and admin dashboard (`src/app/admin`) move
here from `apps/club-sites`, and the universal-link file moves with them.

Lives on the platform's own domain, separate from any club's public site.
